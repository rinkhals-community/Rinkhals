## Kobra 2 Max

!!! warning "Don't install Rinkhals on a Kobra 2 Max"

    A Kobra 2 Max running stock firmware 3.1.2 is offered the 3.1.4 update, and
    Anycubic's update server only offers 3.1.4 under the Kobra 2 Pro's model ID
    (20021). So the Kobra 2 Max most likely identifies itself as a Kobra 2 Pro
    and gets the same firmware file. We haven't been able to confirm this on a
    printer yet.

    If that's the case, Rinkhals will take a Kobra 2 Max on 3.1.4 for a Kobra 2
    Pro and the installer will let it through. Rinkhals has never been tested on
    a Kobra 2 Max, which has a larger bed and almost certainly its own printer
    configuration, so **don't install it on a Kobra 2 Max**. If you own one and
    would like to help, come talk to us on
    [Discord](https://discord.gg/bQcrsteFGU).
