## Kobra 2 Plus and Kobra 2 Max

!!! note "Not supported"

    Rinkhals supports the Kobra 2 Pro only. The Kobra 2 Plus and Kobra 2 Max
    run similar software, but each has its own model ID (20022 and 20023; the
    Kobra 2 Pro is 20021) and its own firmware files. Rinkhals doesn't recognize
    either model, and it won't start on a printer it doesn't recognize.

    Don't try to get around this by flashing Kobra 2 Pro firmware on a Plus or
    Max: the Pro's files don't match their build volume and can leave the
    printer unusable. If you own a Kobra 2 Plus
    or Max and would like to help add support, come talk to us on
    [Discord](https://discord.gg/bQcrsteFGU).
